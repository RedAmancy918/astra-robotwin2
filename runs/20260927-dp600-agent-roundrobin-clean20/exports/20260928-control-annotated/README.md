# Agent 与 DP600：带控制来源标注的回放

已根据逐帧时间、服务端指令起止时间和 command_id 核对全部 6,278 帧。保留原视频帧数、顺序与时长：20 分 55.6 秒。

- 蓝色：DP600 输出关节与夹爪动作。包括固定初始 120 步，以及 Agent 主动委托 DP 的动作段。
- 橙色：Agent 直接下发末端位移或夹爪指令；DP 暂停。
- 灰色：初始化、切换/恢复场景、存档或停止；不归到任何一个策略的动作。

第一局 13.4 秒为 Agent 决策 #1 委托 DP 继续 24 步；18.6 秒首次直接接管，为决策 #3：右手 Z- 5 mm。

视频同时显示决策编号、轮次、当前/最近指令、整批请求和事后执行回执。批内指令按动作计数对齐；部分中间物理过程没有逐帧录制。“指令执行完成”不代表抓取或堆叠成功。“目标未到位”显示回执中的位置误差。

本实验是已训练的 DP600 与视觉 Agent 交替执行；DP600 是无语言条件的 Diffusion Policy，不是另一个通用 VLA。

已记录 715 次 Agent 决策：574 次直接末端控制、141 次委托 DP；另有 20 段固定初始 DP。整局没有重新运行，实验仍处于人工中止状态。
