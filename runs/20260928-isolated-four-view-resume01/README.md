# 四视角 Agent 续跑

从 `20260928-isolated-visual-eval01` 用户停止时的场景继续：之前 72 次模型决策、115 次动作尝试。这是增加第四相机后的续跑，不计作新的独立测试局。

Agent 为 gpt-6-astra / max，接收主摄、左右腕和斜侧面四路当前 RGB。第四路是用户已确认的固定向下俯视 45° 相机，1280×960。原三路为 320×240。模型还接收机器人自身状态、本局自身记忆及最近 12 次动作反馈；继承内容已经与旧阶段模型原始输出逐项核对。

模型输出 EEF 目标、平移和夹爪开合。DP 不参与，无人工补动作。沿用文件系统与进程隔离、禁止工具访问、每次调用输入哈希和文件访问审计。不给模型专家代码、演示数据、其他实验轨迹、物体真值、相机标定、场景种子或当前聊天上下文。

无任务动作数或时长上限。官方成功后继续 500 个物理步（2 秒），全部保持成功才计成功。方块落地为终止失败；基础设施错误单独记录。四路画面按物理时间连续录制为 25 fps，1280×1016，模型思考期间的仿真暂停不占视频时长。

`progress.json` 为当前状态，`result.json` 仅在结束后生成。本阶段 decision/action 计数与之前 72 次决策、115 次动作分开记录。不能从进行中状态推断成功率。

运行时隔离不代表能核实基础模型的预训练数据。场景恢复验证位置、速度和驱动等状态；派生加速度缓存不保证完全一致。
